# Directional wall artwork

Built-in imagegen. Source: `src/assets/motion-v2/wall-directions.png`. Game sprites: `src/assets/walls/0.webp` through `15.webp`. `tools/prepare-wall-art.mjs` crops each cell to alpha bounds and encodes WebP. North/east/south/west bits are 1/2/4/8. Both world walls and drag previews select the matching piece.

## Prompt

Production game artwork: modular medieval stone fortress WALL TILESET, exactly 4 columns x 4 rows, 16 separate sprites, one sprite centered in each equal cell. Transparent alpha background, no ground islands, grass, cast ground shadows, text, labels or guides. Same rugged grey-brown cut stone, moss at foot, thick crenellated battlements, realistic painted classic RTS style. FIXED orthographic elevated camera looking north, screen east is RIGHT, north is UP, NOT diamond-isometric. All wall runs horizontal or vertical on the screen; vertical walls recede upward, with the same height and width as horizontal walls. Pieces designed to join on a square grid: all arms reach identical north/east/south/west connection points at cell boundaries; no end towers on through sections. Equal scale and base alignment throughout. Connections in reading order (bit mask N=1 E=2 S=4 W=8): row1 isolated square stone pier; north end (central pier arm north); east end; northeast corner. Row2 south end; north-south straight; southeast corner; N+E+S T junction. Row3 west end; northwest corner; east-west straight; N+E+W T junction. Row4 southwest corner; N+S+W T junction; E+S+W T junction; four-way cross. These are WALLS with vertical masonry faces and battlement tops, not flat paving. Clear consistent robust geometry, moderately tall defensive walls, compact textures readable at game zoom. NO buildings roofs flags gates people or weapons. Each sprite stays in its own cell; complete silhouette visible.
